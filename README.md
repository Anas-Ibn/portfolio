## 📋 Description

Portfolio professionnel moderne et responsive présentant mes compétences en Data Science, Machine Learning et Intelligence Artificielle. Conçu avec une approche mobile-first et optimisé pour les performances et le SEO.

## ✨ Fonctionnalités

### 🎨 Design & UX
- **Design moderne** avec thème sombre et accents néon
- **Responsive** - Compatible mobile, tablette et desktop
- **Animations fluides** avec CSS3 et JavaScript
- **Navigation intuitive** avec menu hamburger mobile
- **Lightbox** pour visualiser les images de projets

### 🚀 Performance
- **Optimisé SEO** avec métadonnées complètes
- **Lazy loading** des images
- **Compression CSS/JS** pour des temps de chargement rapides
- **Structured data** pour les moteurs de recherche

### 💼 Sections
- **Header** avec photo de profil et CTA
- **À propos** avec présentation personnelle
- **Compétences** organisées par catégories
- **Projets** avec sliders d'images interactifs
- **Blog** avec articles récents
- **Contact** avec formulaire fonctionnel

## 🛠️ Technologies Utilisées

### Frontend
- **HTML5** - Structure sémantique
- **CSS3** - Styles modernes avec variables CSS
- **JavaScript ES6+** - Interactions et animations
- **Font Awesome** - Icônes vectorielles
- **Google Fonts** - Typographie Poppins

### Outils & Optimisations
- **CSS Grid & Flexbox** - Layouts responsives
- **Intersection Observer API** - Animations au scroll
- **Local Storage** - Persistance des préférences
- **Service Worker** - Cache et performance

## 🚀 Installation & Déploiement

### Installation locale
```bash
# Cloner le repository
git clone https://github.com/anasibnouali/portfolio.git

# Naviguer dans le dossier
cd portfolio

# Ouvrir avec un serveur local (ex: Live Server)
# Ou simplement ouvrir Index.html dans un navigateur
```

### Déploiement GitHub Pages
1. Fork ce repository
2. Aller dans Settings > Pages
3. Sélectionner la branche `main`
4. Le site sera disponible à `https://[username].github.io/portfolio`
